# 飞书全流程消息卡片展示约定

消息采用 JSON 2.0，信息顺序和表单限制见 [卡片布局与平台约束](card-layout-verification.md)。当前根层顺序为结果 → 完成确认与反馈 → Devbox 整体区域 → PPE 整体区域 → 编码追溯信息，各环境的状态、访问、设置和详情连续展示。

涉及共享功能时，必须按[双入口同步规则](card-layout-verification.md#双入口同步规则)
同时调整 Meego 网页卡片与飞书消息生成/回调，分别验证并记录生效状态。

## 按阶段展示

| 场景 | 默认可见信息与动作 |
| --- | --- |
| 需求评估待确认 | 结论、需确认问题；确认需求为主操作，反馈/重新评估为次操作 |
| 需求缺信息 | 编号缺失项和反馈入口；无开始 Coding 按钮 |
| 评估执行失败 | 脱敏原因、重试；历史共识注明非本轮结论 |
| Coding/重新 Coding | 当前轮次和进度；无完成或新部署，已有环境按资格独立释放 |
| 编码阻塞 | 部分结果、阻塞项、Agent 测试；根层反馈用于继续 Coding，无完成或新部署 |
| 代码 Review | 简短结果与代码入口，完成确认和反馈相邻；可选部署在其后 |
| 入口待验证 | 区分产物已部署和入口就绪；符合 pending 访问资格时显示入口，不允许业务验证通过 |
| 当前环境就绪 | 显示访问与本轮版本，明确选择验证通过/跳过验证 |
| 更新或旧版本 | 目标与上一版信息可见，旧部署不能验证新轮代码 |
| 释放中/清理失败 | 保留占用和清理状态，不把节点完成当作释放证明 |
| 节点完成 | 代码已确认、历史验证结果、代码入口；必要清理状态保持可见 |
| 编码或完成失败 | 脱敏原因及当前有效重试操作 |

## 可读性与交互

部署消息按业务结果通知；触发、进度与结果采用以下规则，两种环境一致：

| 环节 | 飞书消息与操作反馈 |
| --- | --- |
| 触发部署/重试 | 飞书回调明确提示对应环境“部署请求已受理”，刷新任务卡片；网页沿用 202 响应和最新状态，不另发一条排队消息 |
| 构建、部署、释放处理中 | 任务卡片展示实际阶段，不随轮询刷独立通知 |
| 部署成功 | 独立提示部署完成、待业务验证；访问/释放按钮按服务端资格显示，不自动记录人工验收 |
| 部署失败 | 独立提示脱敏原因；PPE 更新失败注明上一版保留，Devbox 自动清理中注明完成后另行通知 |
| 结果不确定 | 区分“部署结果待确认”和“释放结果待确认”，不把未知结果写成成功或确定失败 |
| 申请释放 | 飞书回调提示对应环境“释放请求已受理”，刷新任务卡片；MAAT 自动清理期间不发待人工提醒 |
| 释放完成 | PPE 须确认环境及所属资源回收，Devbox 须确认本机停服及适用的 MAAT 清理；独立通知一次，无访问/释放按钮 |
| 释放失败/需人工 | 明确资源尚未确认回收及下一步；Devbox 旧端口继续保留，不误写成部署失败 |

PPE 结果通知使用持久化待发送标记，发送失败后重试；释放完成同样适用。
通知身份绑定部署、结果及接收人；PPE 释放失败/待确认还绑定原释放工单，避免吞掉新的人工重试结果。
旧轮代码的正常部署结果不再通知；其资源实际释放完成或释放异常仍可通知。完成节点不等于资源已回收。
此表是本地消息生成与回调的契约；已发出的历史消息不自动撤回，真实宿主渲染仍需人工验收。

- 短共识/测试等详情不超过 160 字且不超过 3 个非空行时直接显示，否则折叠。结果摘要超过 400 字时主区域显示摘要，完整内容在详情。
- 代码/部署提交先显示 12 位，完整 SHA、配置、日志及构建信息可追溯。机器选项只保留名称、在线状态和简短压力信息。
- 根层 form 不放入 collapsible_panel；组件 name 全局唯一。完成选择和按钮可使用 form 内 column_set，窄屏上下排列。
- 飞书反馈限制 1000 字，保留原生计数，占位文字引导长反馈进入 Meego；网页上限 4000 字，不静默截断。
- 节点完成显示“已记录业务验证通过”或“未记录业务验证通过”。后者不推断历史记录究竟未验证还是跳过。
- 业务验证来自用户确认，不能由打开入口、构建完成或健康检查自动写入。访问和验证资格分别核对，历史结论不恢复旧环境资格。
- 部署通知保留简短终态、环境跳转及人工干预提醒；Devbox/PPE 成功通知在 `can_release` 为真时显示对应的“释放 Devbox”/“释放 PPE”按钮。
  PPE 和 Devbox 在实际释放回查通过后，分别提示“PPE 释放完成”/“Devbox 释放完成”；清理中不发人工提醒，完成消息不带访问或释放按钮，重复轮询复用消息去重规则。
  释放复用任务卡片已有回调，仅清理对应环境，不确认业务验证或完成节点；正在释放或已释放时不显示按钮。
  同快照 UUID 稳定，不为轮询、耗时变化或展开详情发新通知。
- 布局标识区分新生成消息，旧消息不自动重发。回调仍核对签名、最新轮次、部署身份、generation、配置及验证目标集合，过期消息不能推进新任务状态。

本地结构/回调测试覆盖表单层级、环境操作归属、签名和过期资格；飞书桌面与手机客户端的实际渲染仍需现场验收。
