# Meego Coding 卡片布局与平台约束

本文记录当前布局、交互约定及验收边界。源码为权威；发布版本与临时截图不作为布局规范。

## 双入口同步规则

Meego 网页卡片和飞书消息卡片是同一任务的两个操作入口。调整共享的任务状态、
展示信息或交互功能时，必须同时检查并同步调整两处。范围包括输入评估、Coding 反馈、
Devbox/PPE 运行配置与推荐依据、部署与重试、访问入口、业务验证、完成节点、资源释放及错误提示。
两处使用同一服务端状态和操作资格；平台专属布局、输入上限和折叠方式可按各自约束实现。

每次此类改动须完成：

- 核对网页入口 `frontend/src/features/ai_node_web_aeolus_card/App.tsx` 及相关 `runtime.js` / `ppe.js`，
  同时核对飞书消息生成与回调 `src/conciliator/services/aeolus_lark_service.py`。
  部署成功/失败等结果通知也要检查其受影响的信息与动作。
- 同步展示选项、推荐依据、状态与可用动作，并核对两个入口提交的轮次、完整 SHA、
  候选 ID、配置 revision、部署身份及验证目标集合；过期或不兼容选择由服务端拒绝。
- 分别验证网页控件/API 请求和飞书表单/回调；按影响范围运行 `frontend/tests/`、
  `tests/unit/test_aeolus_lark_service.py` 及相关 API/服务测试。只验证共享后端不足以证明两个入口均已同步。
- 在变更说明中分别记录两处的实现、验证和生效状态。网页构建需对应前端发布版本；
  飞书消息由后端生成，已发出的旧消息需有效回调刷新或新通知才展示新版。真实宿主未验收时明确记录。

## 网页布局

- 外框占满卡片可用宽度，以容器宽度 1100px 为两列断点。宽屏结果与完成/反馈在左，环境在右；窄屏顺序为结果 → 完成或修改 → Devbox → PPE → 历史。
- 完成操作先于长共识和历史。Review 修改建议默认折叠，阻塞反馈默认展开。长共识、Agent 测试记录、历史、部署设置和诊断按需展开；失败原因、阻塞项和旧版本提示保持可见。
- Devbox 蓝色、PPE 紫色标题/边框区分环境类型；白色内层和状态标签区分运行状态。两者共用版本、访问、操作与折叠详情骨架，按钮高度 36px。
- 主区域展示 12 位 SHA，完整 SHA 保留在详情。PPE 镜像与更新目标可见，更新中及更新失败时保留上一版提示和访问方式。
- 按钮可并排换行，长 SHA、配置名及正文不能撑出整页横向滚动；代码块、表格可局部滚动。
- 同任务轮次的轮询、缩放保留反馈和展开状态；任务/轮次改变后应用新默认状态。可验证目标集合改变后重置验证选择。

## iframe 高度与滚动

根容器保留 `min-height:320px`，不对所有 iframe 强制 `height:100vh`。短初始 iframe 若按内容自动增高，固定 viewport 高度会使内容依赖旧 iframe 高度，导致普通视图压成窄条。

可视高度小于 480px 时按内容布局，允许 iframe 文档纵向滚动；达到 480px 后以可视高度作为 `max-height`，应用根容器承担长内容滚动。480px 是布局断点，不是 SDK 全屏标识。

普通自适应宿主应能测得自然内容高度；短固定窗口由文档滚动，较高固定窗口由应用滚动。没有启用固定操作底栏，也不为每个详情区域新增独立纵向滚动条。

AI 节点公开接口没有全屏属性或 resize API。`displayMode` 属于 AI 操作点位，`resizeContainer` 属于排期组件，不能借用于 AI 节点。真实宿主的高度、overflow 和事件行为仍需现场检查。

## 验证选择与配置控件

Web 和飞书完成确认只有“验证通过”“跳过验证”，无环境时仅提供后者，不默认完成。验证通过确认当前快照中全部可用环境；结构化 `verification_targets` 绑定目标类型和部署 ID，任何目标变化或失效都阻止提交，不静默降为跳过。旧飞书卡片签名绑定原目标集合。

Web 下拉菜单采用白底蓝色样式，挂到页面根部并按可视区域定位；支持键盘、Escape、Tab 和外部点击关闭。离线/不支持仓库的机器不可选，空运行配置不可部署；切换机器不继承上一台配置。两个入口仅采用服务端明确推荐，推荐缺失或失效时要求手选；不兼容配置不能提交，飞书不生成空配置下拉表单。运行时判定与冻结规则见[运行时选择](runtime-selection.md)。

## 飞书信息顺序

根层顺序为当前结果与代码入口 → 完成确认与修改反馈 → Devbox 状态、访问、部署设置、折叠详情 → PPE 状态、访问、部署/重试、折叠详情 → 编码追溯信息。

每种环境只有一个标题，所属配置与操作连续展示。访问入口在根层，完整配置、提交、日志、构建/集群记录和独立释放放入各自详情。异常及旧版本提示不折叠。

表单保持根层；完成选择和提交可使用 form 内 `column_set`，窄屏 `stretch` 上下排列。飞书反馈最多 1000 字，Web 最多 4000 字；原生输入计数保留，长反馈提示放在占位文字。节点完成不掩盖释放中或清理失败状态。

## 回归与现场验收

本地生产 bundle 和模拟 API/宿主已覆盖宽窄屏、短初始高度、固定窗口、普通/全屏模拟切换、滚轮和键盘滚动，以及无环境/单环境/双环境、配置失效和轮询连续性。后端测试覆盖目标集合变化、签名、事务回滚和旧卡片防误操作。

后续改动至少复验：

- 1280px、1600px 宽屏及 800px、375px 窄屏；无整页横向溢出。
- 从 240px 起步的自动增高 iframe；280/480/720/900px 固定窗口；全部详情展开后可到达内容底部。
- Tab、键盘选择、滚轮，轮询/缩放后反馈和展开状态保留。
- Review、阻塞、失败、已完成、旧版本、更新中、释放中、清理待确认；配置和操作不串入另一环境。
- 验证目标过期或改变时不能提交旧选择，当前轮成功 PPE 不显示普通重复部署入口。

模拟宿主测试不能替代真实 Meego 普通/全屏的高度、overflow、滚轮/键盘和全屏切换验收。真实浏览器 200% 缩放、手机软键盘，以及飞书桌面/手机客户端的表单、窄屏选项和首屏层级仍需现场确认。
