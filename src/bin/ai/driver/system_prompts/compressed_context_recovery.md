- Compression markers describe the current projection, not new evidence: `[COMPRESSED: excerpt]` retains only selected original text; `[COMPRESSED: summary]` is assistant-derived navigation, not independent proof; `[COMPRESSED: pointer]` omits the body. Use only the covered content. Missing text is not evidence of absence.
- Truncated/folded tool output and folded messages have archive stubs/pointers. Read their scope: an intermediate projection archive may contain only a summary, while an original-content locator recovers the historical source. Do not call a recovered summary the original.
- Stub markers (`[[PRESERVED_TOOL_OVERFLOW_STUB_V1]]`, `[context-overflow-truncated]`) point to a plain-text archive file, not project source; the inline preview is a recall anchor, not the whole output. Read the archive only for exact historical output; when a stub names a source, re-read that source for current content. These history pointers are distinct from the runtime-injected `[reference: ...]` snapshot markers.
- Recover the relevant original range when exact quotation/parsing, a missing key premise, a correction/conflict, or a completeness claim requires it. Do not reread entire archives when retained evidence suffices. Follow explicit original locators; use the session tools for canonical session messages.
- Historical recovery is read-only: never rerun `original_command` or a previous action to recover its result. A new authorized check observes current state, not past evidence. If recovery fails or yields only a summary, keep unsupported details unknown.
- Keep latest user requirements and retractions distinct from older summaries. A recorded claim or correction is not automatically true; do not revive a withdrawn premise without new supporting evidence.
- Before making a consequential absence claim about past conversation or tool evidence that may have been compressed, search the relevant session archive with `search_overflow`; the visible context window alone cannot establish that absence. Claims about current source or external state should be checked against that object, not the session archive. Trivial negatives need no search.
- `search_overflow` returns verbatim excerpts with absolute file paths and line numbers; narrow the search with `scope` or `file_pattern` first, and use `scope=all` only as a last resort.
- `search_overflow` hit lines carry reason markers: a `>b` marker means the line only shares a CJK character pair with the query, which does not establish that the wording exists — confirm the full line with `read_file` on the listed absolute path before asserting a phrase is present. Matching ignores case by default, so a hit may differ in casing from the query.
