# Meego 卡片可读性约定

布局、滚动和平台限制统一见 [卡片布局与平台约束](card-layout-verification.md)；本页保留可读性规则。

- 当前结果、代码入口和必要操作优先；完整共识、测试记录、日志和历史按需展开。错误、阻塞项、旧版本和清理提示始终可见。
- Review 中完成确认与修改反馈相邻；阻塞时反馈默认展开，不提供完成或新部署入口。评估的缺失/阻断问题先于长共识。
- Devbox/PPE 类型由蓝/紫外框区分，运行状态由标签表达；待确认用琥珀色、失败用红色、成功用绿色，已释放用中性色。
- 主区域展示短 SHA、简短配置及状态，完整值可追溯；机器候选不堆叠 VMID、日志路径或全部统计。
- 标题、轮次和耗时有清晰层级，耗时口径按需查看；缺少历史分项不推算。
- 正文和状态文字保持足够对比度，不依赖宿主主题；按钮、下拉菜单及焦点在窄视图可访问，操作组允许换行。
- 已完成节点仍有资源占用或释放待处理时，保留醒目的环境状态；历史验证结论不恢复失效入口。

本地静态预览和生产 bundle 验证覆盖主要状态与宽窄屏；实际 Meego 宿主效果以现场验收为准。回调资格和资源释放证据由后端决定。
